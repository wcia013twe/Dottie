The proposed post-session update

  1. End or pause a learning session explicitly. A session can finish before the book does. Mark incomplete or no-observation sessions honestly.
  2. Save evidence first. Stable learner/session/event IDs, timestamps, story and target, task, exact cue or hint, teacher outcome, student request, source and relevant presentation conditions. Optional short teacher note; no diagnostic inference from response time.
  3. Run a separate read-only reflection. Compare the completed session with comparable prior events and stated preferences. The current action-planning agent should continue selecting bounded tools. Reflection must not execute tools, grade responses or turn transcripts into confirmed facts.
  4. Produce a small update. What changed, what helped, what remains uncertain, one next-session suggestion, and the IDs of supporting events. If evidence is insufficient: “No new pattern established.”
  5. Publish with review controls. Show observation vs AI hypothesis vs student preference vs teacher-confirmed fact. Teachers can correct or dismiss; student preferences stay editable. Only applicable, reviewed memory should inform later decisions.
  6. Handle retries honestly. One reflection per session revision; no duplicates, no physical action replay. Save the session if the cloud update fails and show pending/failed/updated with an explicit last-updated time. Recompute after corrected observations.

What we can and cannot derive today

Existing teacher records support target/activity/outcome/hint summaries within a temporary story session. They do not support cross-session trends, learner-selected interests, pause effectiveness, fatigue or scanning-route patterns. Those need additional explicit observations and durable learner-linked sessions. Existing local facts are not sent to the agent.

Any new reflection/profile integration needs its own agreed contract and storage implementation. Preserve the deployed demo and bounded action-plan contracts. No cloud deployment or application changes were performed for this audit.
