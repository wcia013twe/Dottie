## Local children’s catalog

Rebuild with `python3 scripts/fetch_children_books.py` (requires network access).
`../book-catalog.js` records source URLs, rights metadata and SHA-256 hashes.
The original source EPUB3 files in `catalog/` are bundled intact, including their
Project Gutenberg notices and license. Cover images are extracted from those
same EPUBs. Project Gutenberg identifies these editions as public domain in the
USA. Search runs locally; opening a book imports it into the existing browser
reader and saves its reading record without changing older shelf records.

## User-supplied Caterpillar scan

The Very Hungry Caterpillar by Eric Carle was imported from the user-supplied
`THE-VERY-HUNGRY-CATERPILLAR.pdf`. Its original 26-page PDF is preserved as
`catalog/very-hungry-caterpillar.pdf`; the EPUB renders each page as an image.
This is a copyrighted user-supplied work, not a Gutenberg/public-domain edition.
No redistribution license is asserted. There is no extracted book-text narration or live teacher-coach checkpoint
integration for this scan. Original visual descriptions are saved separately in
`catalog/caterpillar-visual-descriptions.json` and `story_mode/narration/caterpillar-visual.json`.
All 26 pages have cached ElevenLabs clips using the configured Peter Rabbit voice;
these descriptions are original accessibility narration, not the printed book text.
The reader matches audio against each unique scanned-page caption, and offers replay
and an expandable description. Rebuild audio with
`python3 scripts/build_narration.py story_mode/narration/caterpillar-visual.json`.
Rebuild with `python3 scripts/import_caterpillar.py /path/to/source.pdf`.
`catalog/local-books.json` preserves the entry when fetching the classics again.

## Caterpillar demo activities

`../caterpillar-activities.js` defines ten fixed local opportunities. Three are
active by default (pages 9, 11 and 25); the Demo questions button allows up to
four selected stops. Markers jump directly to an activity; page narration end
automatically offers an unfinished selected stop. Teacher outcomes and optional
answers are stored only in the current browser reading session as demo results.
They do not enter Story MCP, hardware commands or learner evidence. Restart
clears session results and keeps the teacher's chosen plan. Activity prompts use
the existing ElevenLabs voice, with browser speech as an audio failure fallback.
